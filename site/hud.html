Methods

Errors at display time

Now = the current start point. Scene mean = mean |error| over all start points of this scene (every 0.1 s), the same numbers the benchmark computes. Test split = all 192 test scenes from the report (noise levels: 200 ms only). 20 m offset = lateral error + 20 m x sin(heading error); + = arrow left of the target.

Data: nuScenes CAN bus expansion (CC BY-NC-SA 4.0, nuscenes.org, with attribution): derived pose tracks of 10 test scenes and prediction errors, under the same licence. Limits: open-loop replay, one car model (Renault Zoe, Boston and Singapore), latency emulated on recorded timestamps, timings in the report are x86 host timings. Method and full results: docs/MOTION_PREDICTION.md. Data for this page: scripts/export_mpred_demo.py. Code: MIT.

Held-out test split: 192 scenes, 1.04 h

  • 20 m overlay offset at 200 ms: EKF + MLP 0.0164 m vs CTRV 0.0278 m, -41.1 %, better in 180/182 scenes
  • Noise level 1: EKF + ridge 0.0346 m, pure MLP 0.2449 m
  • C++17 vs Python parity: max 4.5e-13 m
  • Real time: 16.1 us p99 per display frame (x86 host, not an ECU)
